## 途中で見つけて直した問題（本版に含む）

- Android縦画面でプリセット保存を始めると名前欄・保存ボタンがシートの外に隠れていた → 自動スクロール。
- Android横画面の設定は内容が画面より高く「閉じる」がスクロールの外 → 常時表示の閉じるを追加。
- 審判の確認の文章がスマートフォン幅で重なっていた → 高さを測って配置。
- 設定ダイアログ（Android）が半透明で背後が透けていた → 不透明。
- UIスケール≠1で `GUIUtility.GUIToScreenPoint` がグループのオフセットを拡大しない（試験用のボタン位置記録だけに影響）→ 補正。
