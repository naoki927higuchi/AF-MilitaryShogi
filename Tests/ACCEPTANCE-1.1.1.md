# AF-MilitaryShogi 1.1.1 受入検証記録

検証日：2026-09-23（JST）。比較元：1.1.0 / 931b672。対象：Windows x64 Release（Unity 6000.6.2f1、Mono）。
成果物：`bin/Release-1.1.1/AF-MilitaryShogi.exe`。配布ZIP・pushは今回の範囲外。

## 変更と情報境界

| 項目 | 結果 |
|---|---|
| ツールチップ | 敵駒のRenderer Boundsの8頂点をスクリーンへ投影。全体から余白を取り、右優先・左/上下回避、主要UI回避、画面内制限。カーソル座標はホバー/UI上判定のみに使用 |
| 客観情報 | Enemy番号・位置・移動履歴・経路長・飛び越し枚数・自軍戦闘相手・結果・未移動を維持 |
| 判明 | Observation層のPlayerKnownFacts。公開観測で候補を除外し、1種類だけなら判明。CPU Knowledge・確率・敵真値には非依存 |
| 撃破後 | 候補と判明を保持。研究モード戦闘履歴にも表示。敵駒描画には候補や判明を渡さず、常に裏面 |
| 盤面 | Pitch 54度・FOV 36度を維持。投影行列の上下オフセットで上へ配置。通常/終局で同じ位置 |
| 死亡駒 | 左右共通3列×最大11段・78%。自軍は表面・駒種順、敵軍は裏面・撃破順 |
| ロゴ | Generatedのみ2行へクロップ（934×300）。UserProvided原本とアプリアイコンは不変 |
| 初期配置 | CPU設定／自軍の配置／対局開始を見出し・余白で分離。機能・乱数・配置ロジック不変 |
| 戦闘文字 | Popup生成と両UI描画経路を削除。終局結果モーダルを維持 |
| あそびかた | 既存構成・停止動作・ルール由来の相性表と移動図を維持 |

## 既知の制約・未実施事項

- 自動検証の対象範囲で既知の不具合なし。
- Windowsの実カーソル設定を変更する試験、および複数4Kモニター間のDPI切替を伴う人手の操作試験は未実施。UIスケール付き除外領域と実4K描画まで確認した。
- ツールチップは最新の履歴を最大12行程度表示する。過去の戦闘は研究モード履歴で確認でき、観測データ自体は保持する。
- ウィンドウを極端に狭くして全UIと駒周辺の余白を同時確保できない場合、画面内収まりと駒からの離隔を優先し、主要UIとの重なりを最小化する。
- 初回の非表示ウィンドウによる旧版試験はロゴRepaintが発生せず失敗した。検証スクリプトは描画可能な通常起動で同期実行する形にし、再検証した。
- 初回Unityビルドは実行環境のライセンス接続制限で停止。許可された実行環境で再実行しReleaseビルド成功。旧1.1.0の出力は変更していない。
