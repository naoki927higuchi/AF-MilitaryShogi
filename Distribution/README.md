# 最新バイナリー

公開用に選定・検証したWindows版です。

| 製品 | 最新版 | SHA256 |
|---|---|---|
| [AF-MilitaryShogi（ZIP）](AF-MilitaryShogi-1.6.0-Windows.zip) | 1.6.0 | [チェックサム](AF-MilitaryShogi-1.6.0-Windows.zip.sha256) |

Windows 10 / 11（x64）用です。別途用意するランタイム・外部ツールはありません。ZIPをすべて展開して `AF-MilitaryShogi.exe` を起動してください。

1.6.0 の主な変更：あそびかたの移動図の線のずれと、ウィンドウの横幅だけを変えたときの盤の歪みを修正。CPUの強さ・戦い方を次回起動へ引き継ぐ。初期配置中は「新規対局」を押せないようにした（配置を誤って消さないため）。詳しくは [HISTORY.md](../HISTORY.md)。

AndroidのAPKは配布していません（Android版は開発者の端末での実機確認用）。Android対応を含むソース一式から、各自の環境でビルドできます。
